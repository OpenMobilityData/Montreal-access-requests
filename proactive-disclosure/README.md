# Proactive-disclosure downloads

The Ville de Montréal publishes responses to access requests, with personal information removed, on its proactive-disclosure portal: dataset [*Diffusion proactive – Documents remis des demandes d'accès à l'information*](https://donnees.montreal.ca/dataset/diffusion-proactive-acces-information) (City of Montréal open data, CC BY 4.0). The dataset is an inventory (CSV) with one row per published response and a link to the PDF on `depot.ville.montreal.qc.ca`. The inventory changes over time and has not been complete: some responses known to have been released are not listed in any version consulted (see [`../2022-1447/README.md`](../2022-1447/README.md)).

The copies here are kept so that the documents remain available with their provenance if the portal changes. Each theme folder has one PDF per portal entry, under the file name used on the depot, and a README quoting the entry's inventory row (columns `Numero_demande`, `Categorie`, `Sujet`, `Service_Arrondissement`, `Date_reponse`, `Date_ajout`, `Lien_vers_document`) verbatim and giving the date the copy was downloaded.

| Folder | Content |
|---|---|
| [`budget/`](budget/) | Côte-des-Neiges–Notre-Dame-de-Grâce: borough revenues since 2017 (2022-131), accumulated surpluses 2018–2023 (2023-502) |
| [`cycling/`](cycling/) | Cycling network and its cost, 2021–2024: CDN-NDG plan and 2023 projects, Bourret counts, network length, Ville-Marie projects, REV Saint-Denis, Vélocité des lieux, Plan vélo budget |
| [`inventory/`](inventory/) | Dated copies of the inventory CSV: December 23, 2024; February 28, 2025; October 17, 2026 |

The PDFs are reproduced as published, with the City's and boroughs' redactions. One file, `budget/3-2022-131.pdf`, carried the requester's e-mail address in a hidden link under the borough's black box; the link target was blanked by the repository owner (see [`budget/README.md`](budget/README.md)).
